How the Auto-Post Works

→ GitHub Actions triggers daily at 7PM PHT
→ Groq AI generates a unique horror story
→ Pollinations.ai creates 3 horror images
→ Edge TTS narrates the story with matching voice
→ FFmpeg assembles the final 1080×1920 Reel
→ TikTok Content Posting API uploads via video.publish
→ Reel goes live on @storyxlabofficial
