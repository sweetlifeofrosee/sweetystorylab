# SweetyStoryLab

This repository hosts the public website for **SweetyStoryLab** via GitHub Pages.

🌐 **Live site:** https://sweetlifeofrosee.github.io/sweetystorylab/

## What's here

This repo contains only the public-facing website — static HTML pages and
site assets. It does not contain any application code, automation, or
publishing logic.

| File | Purpose |
|------|---------|
| `index.html` | Homepage |
| `privacy-policy.html` | Privacy policy |
| `terms-of-service.html` | Terms of service |
| `callback.html` | TikTok login callback page |
| `tiktok-auth.html` | TikTok-related informational page |
| `logo.png`, `favicon.png`, `favicon.svg` | Site branding assets |
| `sweetystorylab_qr.jpg` | QR code image |
| TikTok domain-verification file | Confirms domain ownership to TikTok |


## Making changes

This site is served directly from the `main` branch via GitHub Pages —
changes pushed here go live automatically. Please keep this repository
limited to public website content only.
